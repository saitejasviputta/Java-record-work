# ☕ Java Record Work

A collection of Java lab programs and practical assignments, organized week by week for easy learning, revision, and reference.

🌐 **Live Website:** [Java Record Work](https://saitejasviputta.github.io/Java-record-work/)

---

## 📌 About the Project

**Java Record Work** is a web-based Java lab record created to organize and present my Java programming practicals for the academic year 2026.

The website provides a simple way to explore lab questions, view their corresponding Java programs, and understand their outputs in one place.

Instead of going through a traditional lab record, users can browse the programs by week or use the search feature to find specific topics.

## ✨ Features

- 📚 **Week-wise Organization:** Browse Java lab programs organized by week.
- 💻 **Program Listings:** Explore Java practical questions and their corresponding code.
- 📤 **Output Display:** View the expected output of the programs.
- 🔍 **Search Functionality:** Find programs using relevant keywords, such as constructors, threads, and interfaces.
- 🌐 **Web-Based Access:** Access the record directly through a browser.
- 🎓 **Academic Reference:** Use the collection for revision and practical preparation.

## 🛠️ Technologies Used

- **HTML** — Web page structure.
- **CSS** — Styling and layout.
- **Java** — Programming language used for the lab exercises.

The primary objective of this project is to maintain an organized digital record of Java laboratory exercises while making programming concepts and practical solutions easier to access and revise.

It also serves as an opportunity to practice web development and present academic work in a more accessible format.
